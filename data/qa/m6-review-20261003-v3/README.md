# M6 冻结人工评审材料（可从 GitHub 领取）

这是原 `data/processed/m6-blind-20261003-v3/` 中必需评审输入的受控副本，不是新生成的题目或新一轮成绩。
全套材料随 Git 提交，clone 后即可领取；数据库、运行归档、临时容器数据、契约报告及人工评分输出不在此目录。
完整操作见 [组员交接指南](../../../docs/M6独立人工评估交接指南.md)。

## 先阅读：分目录不是权限隔离

按用户要求，本目录同时提供两阶段材料及协调人评分包。**仓库读者技术上能访问所有文件，不能声称存在访问控制。**
协调人应只分发当阶段所需文件。评审在封存意图前不得浏览 `answer-review/`、`coordinator/` 或问答路由代码。
`predictions.private.json` 中的 private 表示角色用途，不表示 GitHub 私密／加密；其中是系统预测，不是人工正确答案。
若评审已提前看过回答、预测或对应关键词实现，记录泄漏情况，另选未接触这些内容的人；
无法满足时只能报告为非盲评，不应包装成独立盲评成绩。

## 文件领取与交回

| 阶段／用途 | 必需文件 | 谁可以在何时查看 |
|---|---|---|
| 意图盲标 | `blind-intent/questions.csv`、`intent-A.csv`、`intent-B.csv`，根目录 `INSTRUCTIONS.md` | A、B 第一阶段，各自仅填写本人模板 |
| 答案／证据评分 | `answer-review/responses.json`、`reference-sources.json`、`ratings-A.csv`、`ratings-B.csv` | 两份意图标签封存后，A、B 各自填写本人模板 |
| 分歧仲裁 | `coordinator/adjudication-template.csv` | 意图有分歧时，由不同第三人填写 |
| 最终机器评分 | `coordinator/predictions.private.json` | 协调人使用，不发给盲评者；不能抄预测当人工标签 |

共 10 份评审输入文件。两位评审各处理 53 条意图及 53 条答案／证据评分。
先将空白模板复制到协调人的私有回收位置，保存已填写副本和封存记录，不在此目录覆盖冻结输入。
实际评审 ID、已填写的人工研究记录和评分结果另行私下备份，不随意公开参与人身份。
