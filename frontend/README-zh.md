# PharmaColdOps 演示前端 · 操控说明

> 这是一个**离线**演示前端（`index.html` 英文 / `index-zh.html` 中文 + 数据文件 `real_data.js`），用浏览器直接打开即可，无需联网。
> 场景与配送数据来自**真实下载的数据集**（Kaggle 疫苗温度日志 + Solomon VRPTW），由 `scripts/export_demo_data.py` 生成 `real_data.js`。
> 核心规则引擎是 Python 版 `src/rule_engine/engine.py` 的忠实 JS 移植，**你在界面上做的每一步判断结果都和真实引擎一致**。
>
> 📡 **前后端分离版（2026-09-09 起）**：URL 加 `?api=http://127.0.0.1:8000` 即切换到「全后端」模式——判定、热力图、预置卡全部由 FastAPI 后端（`src/api/`，跑真 Python 规则引擎）算，后端不可达时自动兑底回本页。技术栈与连接说明见 [docs/前后端技术栈与连接说明.md](../docs/前后端技术栈与连接说明.md)。

## 一、界面分区

| 位置 | 区域 | 性质 |
|---|---|---|
| 左栏 | 场景预设 + 规则配置 | ✅ 可操控 |
| 中栏 | 决策沙盒（回放 / 输入 / 热力图 / 证据） | ✅ 可操控 + 实时响应 |
| 右栏 | 配送重新规划 + 合规问答 | ✅ 可操控 |
| 底部 | 审计追踪 | 自动记录 |

## 二、你可以在界面上操控的每一个东西

### 左栏

**1. 场景预设（18 个真实事件）**
- 点击任意卡片，把该事件加载进沙盒，同时把产品阈值重置为该产品的默认值。
- 每个卡片上的色点表示该场景的处置结果（绿=放行、黄=复验、橙=隔离、红=报废）。

**2. 规则配置（改阈值，全局生效）**
| 控件 | 作用 |
|---|---|
| 允许超限时长（分钟） | 改规则 2/3/4 的时长阈值，热力图边界会跟着变 |
| MKT 阈值（°C） | 改规则 2/3/4 的温度阈值，热力图边界会跟着变 |
| 可复验（勾选） | 取消勾选后，规则 4 失效，冷冻品默认就是不可复验 |
| 重置为产品默认值 | 一键还原当前产品的阈值 |

> 演示「系统可配置」：现场把「允许时长」从 30 改成 20，同样的超限事件可能从放行变成隔离。

### 中栏

**3. 温度回放**
| 控件 | 作用 |
|---|---|
| ▶ 回放 / ⏸ 暂停 | 让「当前时刻」光标扫过整条温度曲线，越限时右上角弹出红色 ⚠ 超限 |
| 进度滑杆 | 手动拖到任意时刻，看那一刻是否越限 |

- 曲线**由当前事件参数实时生成**：绿色段在安全区（min–max 阴影带）内，红色段越限。你改「超限温度 / 时长」，曲线形状跟着变。

**4. 超限输入（核心沙盒）**
| 控件 | 作用 |
|---|---|
| 产品下拉 | 切换产品（疫苗 2–8 °C / 冷冻 −25…−15 °C / 胰岛素 2–8 °C / mRNA −90…−60 °C），阈值与默认事件一起切换；冻敏产品（疫苗/胰岛素）降到 0 °C 以下会触发冻结报废规则 |
| 阶段下拉 | 运输中 / 仓库 / 机场滞留 / 最后一公里（影响根因提示与展示） |
| 包装下拉 | 改成「破损」且超限温度 > 上限 → 触发规则 1，直接报废 |
| 超限温度 滑杆 + 数字 | 拖动实时重算 |
| 时长 滑杆 + 数字 | 拖动实时重算 |
| MKT 滑杆 + 数字 | 拖动实时重算 |
| 🎲 随机超限事件 | 摇出一个新事件，并记入审计追踪 |

**5. 决策边界图（时长 × MKT 热力图）**
- 这张图**不是死图**：上面那个白边圆点就是「当前事件」所在位置。
- **拖动「时长」或「MKT」滑杆，圆点会实时移动、跨越阈值虚线**，顶部处置标牌跟着从 放行 → 复验 → 隔离 → 报废 连续翻转。

**6. 以下四块是「实时响应」展示区（无需操作，自动跟着变）**
- 可审计规则路径：一行完整可审计的 `产品…→ 处置：原因`
- 规则评估：6 条规则（含冻结损坏规则），命中的那条高亮
- 风险指数 + 首要根因（**规则启发式 · 确定性评分**，与规则引擎同一组阈值，非 ML 模型）
- 为什么这么判：包装/温度/冻结风险/时长/MKT 逐项 vs 阈值，配「正常/接近/超出/严重」状态章 + 法规依据（WHO/GDP）

### 右栏

**7. 配送重新规划**
| 控件 | 作用 |
|---|---|
| 优化方案 / 原始方案（基线）切换 | 切换路线（青色实线 vs 红色虚线），下方四指标（距离/时长/成本/违规数）跟着变 |
| 点选药房节点 | 高亮该药房，显示时间窗、温区、需求量、第几站 |

- 注意：只有处置结果是**报废或隔离**（需要补发）时，路由图才出现；放行/复验时显示「无需路由」。

**8. 合规问答（知识图谱 · 概念示意）**
- 输入问题点「提问」或按回车，返回基于法规的回答。
- 可试的关键词：`MKT` / `报废` / `隔离` / `复验` / `放行` / `配送` / `GDP`。

### 底部

**9. 审计追踪**
- 点「🎲 随机超限事件」时自动新增一条记录（时间 / 场景 / 产品 / 处置 / 规则路径），最多保留 8 条。

## 三、建议的演示流程（约 1 分钟）

1. **讲规则**：点一个预设场景（如 S017 隔离），指着「规则评估」里高亮的那条讲清楚为什么。
2. **秀决策边界**：把「时长」滑杆从 20 一路拖到 65，让观众看着热力图圆点跨过三条虚线、处置连续翻转。
3. **秀可解释**：指着「为什么这么判」逐项说「温度超了、时长接近阈值 → 所以复验」。
4. **秀异常检测**：点 ▶ 回放，让温度曲线越限、弹出 ⚠ 超限。
5. **秀补发**：切到报废/隔离场景，点「优化方案 vs 原始方案」看成本/违规对比，再点一个药房节点。
6. **秀可配置**：现场把「允许超限时长」从 30 改成 20，看同一事件结果变化。

## 四、注意事项（如实说明）

- **真实逻辑**：规则引擎（6 条优先级规则 → 放行/复验/隔离/报废 + 补发标志，含冻结损坏规则）是真实的，判断结果与 Python 引擎一致；每个决策还带文档级法规引用（WHO TRS 961 Annex 9 / EU GDP）。
- **部分真实 + 部分概念示意**：场景事件（温度/时长/地点）与配送数据（Solomon VRPTW 坐标/需求/时间窗）是**真实下载数据**；风险指数是**规则导出的确定性评分**（非 ML 模型，见下）；配送路线求解（最近邻 + 2-opt 简化启发式）与知识图谱问答仍是**概念示意**，答辩时需说明哪些是 mockup。
- **风险指数 ≠ ML 模型**：界面上的 0–100 风险指数由规则引擎同一组阈值（温带/允许时长/MKT）导出，可解释、确定性、随滑杆实时变化。真正的**训练模型只存在于离线报告**（`scripts/train_risk_model.py` 在 silent-failure 上训 LogisticRegression，AUC≈0.89 / PR-AUC≈0.67，但该数据集疑似合成，指标仅代表生成器、不代表真实世界）。
- **阈值是占位值**：`2–8 °C 允许超限 30 分钟` 等阈值需按 WHO TRS 961 Annex 9 / EU GDP 2013/C 343/01 及供应商稳定性数据确认后替换；mRNA 的阈值是「单阈值近似」其厂商多级稳定性窗口（解冻后 2–8 °C ~30 天 / 室温 ~6h）。
- **冻结规则是真实依据**：冻敏产品 ≤0 °C → 报废，对应 WHO TRS 961 Annex 9「冻敏疫苗冻结即失效」；法规引用目前只到文档/附录层级，答辩前需核实具体条款号。
- **真实数据的诚实说明**：`mkt_c` 由单点温度读数近似（源数据无 MKT 列）；`packaging` 固定为 `intact`（源数据无此字段）；`stage` 由真实 `current_hop` 映射；产品类别由温度区间推断（源数据无 `product_id`）。字段映射逻辑见 `scripts/export_demo_data.py`。
