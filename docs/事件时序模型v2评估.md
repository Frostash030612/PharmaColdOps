# 事件时序模型v2：多故障、电源／燃料与压力泛化实验

2026-10-04，接续[拒判与审核门禁](事件模型拒判与审核门禁.md)。
已完成独立v2输入、混合背景训练、固定预算对照及冻结后新事件评价。
**时序观测有明显改善，90%候选门槛未降低，但极端压力和多故障遗漏仍不能自动处理。**
当前演示服务、旧月度原因／风险模型、v1门禁和人工审核依据不变；没有自动推广v2。

## 1. 改什么、不改什么

保留v1工程物理、产品配置、噪声／传感器结构和隐藏机理发生标签，v2不是重新编造“容易预测”的标签。
新的 `event-temporal-study-v2` 表示新的训练覆盖和输入契约，不代表厂家标定或药品质量模型。
新增两项：

- 训练中明确混合nominal／stress背景各3,000事件，不再只让模型看常规背景。
- 从同一公开观测前缀提取111项输入：原33项＋四个相对时段的60项统计＋18项时序／联合统计。

四段按**已观测截止时间**等分，不用未来故障时间或实际结束时间；跨段区间精确裁剪权重，不能按行数假设等长。
分段温度、温差、环境、门、电源、备用指令／运行、燃料、电流、冷却、气流、设定点、进度和覆盖率都来自带噪观测。
联合输入包括断电时燃料均值／低分位、低燃料已知时长、备用运行比例、首次观测主电源中断前后燃料差、
电力可用时电流、冷却指令高但电流低的时长、气流变化、温差分位及温度缺口。
“首次断电”也可能是背景波动或误报码，不被当成已确认故障。

缺条件／缺观测的均值和变化量为null，**不填0冒称正常**；已知条件未发生的计数才可为0。
中位数／缺测指示和产品OneHot仅在train拟合，输入拒绝额外ID、角色、标签、计划机理／参数和乱序列。
原33项值保持一致；111项不能直接喂给当前33项事件运行器或13／15项线上M4模型。
货量、仓库余额、日末五仓库停车／医院不能日末停车边界没有新增或改写。

## 2. 新批次与冻结流程

固定seed=20261014（随机流编号，不是未来业务日期），共 **10,200事件／9,597家庭**。
角色定义提前写入protocol：

| 角色 | 事件数 | 背景／范围 |
|---|---:|---|
| train_nominal／train_stress | 各3,000 | 常规／已覆盖压力，各占训练一半 |
| validation_nominal／validation_stress | 各600 | 独立虚拟设备、相同两种参数范围 |
| test_nominal | 600 | 常规背景，新32台设备 |
| test_device | 600 | 常规背景，另一组新8台设备 |
| test_scenario | 600 | ramp／two_pulses未见激励，新设备 |
| test_stress | 600 | 已覆盖的压力范围，新设备 |
| test_extreme | 600 | 超出训练背景范围，新设备 |

所有角色独立seed／设备，验证和nominal测试都不是“同设备纯IID”；两种常规测试是不同的新设备批次。
nominal：环境18–35°C、温度观测噪声0.08–0.35°C、丢包0.015–0.08；
stress：40–48°C、0.6–1.2°C、0.15–0.30；extreme：48–54°C、1.2–1.6°C、0.30–0.40。
stress是训练覆盖内泛化，extreme才是更远背景外推；范围端点可相接，实际观测可重叠。
这里只扩展环境、**温度**测量噪声和丢包；辅助通道误差与设备动力学仍遵循v1，不宣称覆盖所有实车噪声／故障。

原生成器的压力采样器被用于**提前声明的新train_stress／validation_stress**，并非拿旧测试文件训练。
不同角色派生不同seed，隐私sidecar中的采样器名字不是预测输入。
所有正常、未知、多故障、观测等价和弱可见机理保留，不因未超温或次要机理不明显而删除。

程序只先生成train／validation，拟合后冻结全部模型、阈值和策略，**再生成五种新测试**。
全10,200行观测／特征／目标／索引一致；18次重放、18次未来故障前缀不变和603对歧义检查通过。
各角色家庭／设备／111项精确画像交集0；与旧v1及上一轮新6,000批次的家庭／设备／33项画像交集均0。
发生重叠或校验失败就停止，不重采样刷成绩；原源文件／基线哈希在前后验证。
同一未标定仿真器的新随机流是独立仿真事件，**不是独立真实业务有效性或新原因开放集验证**。

## 3. 四组预先固定的对照

| 探针 | 数据／输入 |
|---|---|
| frozen_v1 | 原事件HGB与阈值原封不动，未重新训练；不是线上月度原因模型 |
| mixed_aggregate | 新6,000混合训练，原33项摘要 |
| mixed_temporal | 同一6,000混合训练，111项时序／联合观测 |
| shuffled_temporal | 相同111项，训练家庭标签集合在同产品／家庭大小内打乱 |

三个新模型均是11个独立HGB，100轮、15叶、学习率0.1、L2=1、无早停、seed42，单次固定预算，不搜索大网格。
候选阈值仅由两验证角色合并的逐标签F1决定；旧HGB保留原阈值。
全部探针使用**新训练侧33项包络**和新验证侧策略评价；这不是重现旧门禁，也没有改写旧门禁bundle。
沿用既有证据覆盖80%、未知分数0.2、语义歧义检查及同一筛选网格：至少30支持、完整集合精确率≥90%、正常受支持误报≤5%。
选择仅在mixed_aggregate／mixed_temporal中进行：验证合格策略优先、最大支持覆盖，再两验证角色等权平均macro-F1。
合并验证可掩盖子组弱点，所以所有角色分开报告；两个方法的变化包含训练覆盖／样本量／阈值和输入变化，不做真实因果归因。

## 5. 不可辨识不是单纯调参问题

保留门未关／人员操作等价对，新增专项反例验证：
备用燃料故障已驱动同一断电区间时，额外注入同区间的主电源故障，所有公开观测、111项输入完全相同，
但真实注入集合由{燃料}变为{燃料,主电源}。
这是原v1物理的遮蔽效应，不是错误修成同标签，也不声称所有多故障都不可辨识。
仅凭这些观测不能保证完整集合；不能删隐藏次要机理／弱可见事件或加真实fault_active输入来刷精确率。
未来应明确候选集合完整性的不确定性和缺失的可观测证据，继续人工确认。
