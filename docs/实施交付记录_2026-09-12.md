## 1. 本轮成果

### 1.1 新加坡真实道路配送算例

- 已提交 `data/optimisation/singapore/network.json`，包含 1 个仓库、10 个配送点、11×11 有向距离/时间矩阵及对应道路几何。
- 贪心与 OR-Tools 均能完成全部 10 个配送点，结果可导出为 JSON、GeoJSON，并可加载到 Vue 地图。
- 当前算例是固定的 1 仓库 + 10 配送点全量优化，用于演示和算法比较；尚不是按单笔补发订单动态增删节点的生产调度系统。

详细假设和复现方式见 [singapore_network_assumptions.md](singapore_network_assumptions.md) 与 [M5_singapore_handover.md](M5_singapore_handover.md)。

### 1.2 补发单、路线与知识图谱接口

- 新增 Python `ReshipmentOrder`，使用 `RO-{run_id}` 与知识图谱中的补发单保持同一标识。
- 异常事件支持可选的 `facility_id` 和 `destination_facility_id`。
- `POST /api/route` 已从占位接口变为真实路线接口：读取已结案案例，确认需要补发，再调用贪心或 OR-Tools。
- 路线响应包含车辆数、距离、准时率、服务数、各类违规、站序以及与本次求解站序一致的 GeoJSON 道路折线。
- `POST /api/qa` 已接入 4 类结构化知识图谱查询：处置原因、审计链、产品要求、处置统计。
- 未知案例返回 404；案例无需补发或输入不合法返回 422；Neo4j 不可用时问答返回 503。

接口字段和边界见 [接口契约.md](接口契约.md)。

### 1.3 Vue 前端接线

- 归档案例现在会保留 `run_id`；用户修改产品、场景、温度、时长、包装、环节或规则后会清除它，避免旧路线被误当成当前结果。
- 配送面板在 API 在线、案例已结案且需要补发时，显示该案例的真实后端路线、指标、站序和道路地图。
- 贪心与 OR-Tools 结果按 `run_id + algorithm` 缓存，并预取两种算法以显示距离节省。
- 未结案、无需补发、API 离线或路线请求失败时，继续显示固定演示路线，并明确标注当前数据来源。
- 合规问答把有限关键词映射到 4 种结构化问题类型；需要案例的问题会使用当前 `run_id`，产品要求使用当前产品。
- API 或 Neo4j 不可用时，前端回退原有本地关键词回答，并明确标注“离线示意，非真实查询”。
- 旧版 `frontend/` 没有改动；本轮接线位于 `frontend-vue/`。

具体前端字段和状态切换见 [前端接线契约.md](前端接线契约.md)。

## 2. 前端如何看到区别

启动后端和 Vue 前端：

```bash
cd /Users/wang/Desktop/PharmaColdOps
.venv/bin/python -m uvicorn --app-dir src api.main:app --host 127.0.0.1 --port 8000

cd frontend-vue
pnpm dev --host 127.0.0.1
```

在线联调入口：

```text
http://127.0.0.1:5173/?lang=zh&api=http%3A%2F%2F127.0.0.1%3A8000
```

可见验收步骤：

1. 没有已结案补发案例时，配送面板显示“固定演示路线”。
2. 创建并结案一个 `scrap` 或 `quarantine` 案例后，配送面板先显示“正在计算…”，随后显示“当前案例真实路线”。
3. 切换贪心与 OR-Tools，地图、距离、车辆、站序和节省比例随真实接口结果更新。
4. 结案 `release` 案例，或修改当前案例输入，面板回到固定演示路线，避免展示过期结果。
5. 在问答面板输入处置原因、审计链、产品阈值或统计类问题；API/KG 可用时显示真实答案和 evidence，不可用时显示带离线标识的兜底答案。

不带 `api` 查询参数的 `http://127.0.0.1:5173/?lang=zh` 是离线演示模式，不会调用后端，因此看不到实时路线接线效果。
