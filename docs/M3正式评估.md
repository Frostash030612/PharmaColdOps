# M3 真实引擎正式评估

2026-10-03；rubric v1.1；本报告补齐 proposal §8.1／§8.3 的四类指标、κ、覆盖与失败分析。
结论是**冻结合成场景上的历史人工一致性**，不是临床质量、真实效价或制造商稳定性验证。

## 方法与复现

`scripts/evaluate_m3_formal.py` 直接调用真实 `RuleEngine.evaluate`，不是旧工具的 rubric selftest。
读取不含 gold 的 `data/scenarios/annotation/input_v1.csv`，按唯一 scenario_id 加入
`data/scenarios/gold_labels.csv` 的 57 条仲裁标签；重复、缺行和非法标签直接失败。
不读取或发布 B/C 私有原答，不修改 gold／规则，也不以运行中的人工有效处置覆盖自动预测。

```bash
LOKY_MAX_CPU_COUNT=1 .venv/bin/python scripts/evaluate_m3_formal.py --output data/processed/m3-formal-new
```

仅允许新输出目录。本轮完整 JSON、逐例预测 CSV、Markdown 和混淆图位于
`data/processed/m3-formal-20261003/`；生成物不入 Git，报告记录输入、gold、规则和代码 SHA-256。
四类固定入宏平均，未预测出的类别按 zero_division=0 计，不能删去隔离类来提高指标。
指标口径参见 [scikit-learn classification_report](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.classification_report.html)。

## 实测结果

一致 **54/57 = 94.7368%**；引擎↔gold Cohen's κ **0.909667**；
macro precision **0.688889**、macro recall **0.750000**、macro-F1 **0.717437**；weighted-F1 **0.922822**。
历史 B↔C κ=**0.6434** 是另一项标注者间统计，本轮未重算，不能与 0.909667 混用。

|---|---:|---:|---:|---:|
| release | 13 | 0.866667 | 1.000000 | 0.928571 |
| retest | 8 | 0.888889 | 1.000000 | 0.941176 |
| quarantine | 3 | 0.000000 | 0.000000 | 0.000000 |
| scrap | 33 | 1.000000 | 1.000000 | 1.000000 |

混淆矩阵：行=gold，列=自动引擎。引擎不输出 quarantine，隔离召回 **0/3**；
不能用总体 94.7% 掩盖这项边界，也不能由仅 33 个报废场景推断真实世界报废召回。

这是书面规则版本与历史仲裁的已知差异，不擅自认定任一侧为临床真值。rubric v1.1 的隔离规则出口已取消，
但历史三条 gold 保留；低温／产品级依据缺口不靠改标签或人为添加阈值填补。
如未来获得独立领域依据，应版本化规则并以独立新增案例验证，不能把同批 gold 上调优称作新独立评估。
系统现有人工审核可改变后续配送的**有效处置**，但保留原规则快照，详见
[人工审核与有效处置](人工审核与有效处置.md)。审核闭环不等于本表的自动引擎表现得到提升。
