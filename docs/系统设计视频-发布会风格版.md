## 数字与口径来源

全部来自 [`FINAL_REPORT_EN.md`](FINAL_REPORT_EN.md)：

  54/57 一致，3 个漏判都是 quarantine 类（§6.1）。

  R101/R201 差约 0.17%；RC101 用了 16 辆车（参考 14 辆），不算胜出；GA 没有超过 OR-Tools（§6.4）。
  VRPTW 动画是**示意图**，画面上已注明，不是求解器输出。
- **模型**：风险模型 PR-AUC 0.7087、ROC-AUC 0.9045、Brier 从 0.1091 降到 0.0933（§6.2）；事件级 v2 的
  macro-F1 为 0.7668（nominal）到 0.6505（extreme stress），全部候选仍需人工复核（§6.3）；
  月度原因模型 macro-F1 约 0.13。
- **图谱**：节点和关系名来自 `KG_SCHEMA_v1.md` §3；Neo4j 截图为 `proposal/figures/kg-neo4j-browser.png`。
  五类查询和失败状态见报告 §4.3。
- **可靠性**：2026-10-17 的隔离回归测试 926 项通过、0 项跳过，另有 36 步 API 走查和 9 项前端检查（§7）。
