## 组员下一步

1. 先看画面版与[四人分工](最终答辩分工与录制交接.md)，核对自己实际参与部分。
2. 按CSV理解事实、自己组织表达并真人录制，可交分段WAV／M4A／MP3，或整段5分钟旁白。
3. 文件名写清视频、讲解人、起止时间与语言，例如`system-B-01m25-02m40.wav`，片头保留约0.5秒干净余量。
4. 不用AI配音／克隆音色，不虚构个人贡献、真实业务、临床批准或已完成B评审，不把脚本化界面审核当真人独立评估。
5. 交回真实音频后合成、调音量与字幕；必要时按实际发言调整画面，不机械拉伸声音凑时长。
6. 完整播放终版确认音画和时长，核对最新M6状态与命名后再组包。

只有真人录音到位并完成终审，才另导出没有草稿标识的新终版；不能只去掉标识就声称完成真人视频。

## 工具复建

隔离服务：`scripts/serve_video_demo.py --output data/processed/NEW_RECORDING_DIRECTORY`，需要项目评测环境和Docker。
创建输出目录的STOP文件可停本轮服务，只清理它创建的图谱和子进程，不重建8080图谱。
录制用`scripts/record_business_video.cjs`，Playwright CLI通过`#video=generator/parking/urgent/incident/review/delivery/qa/audit/parking-offline`选择镜头。
它只接受显式非8080／8000的loopback API；必须用独立新模拟库，不用于真实业务或现有演示库。

编码：`scripts/build_demo_videos.py --help`，需要Python3.12、Pillow与支持libx264／libass的FFmpeg；视频工具独立放忽略目录，不改API依赖锁。
默认本机Arial；其他平台传实际可读的`--font`／`--bold-font`。
输入需真实录屏及核验manifest、对应最终PPT的验证回执／PNG，以及按PPT技能确认且保留可见内容的增强副本。
输出用新`data/processed`目录，保留逐镜头时长检查、全片解码报告与SHA，不覆盖旧版。
工具不生成真人声音、不自动上传或Canvas提交，也不把无音轨草稿自动组为最终课程包。
