## 0. 结论（先看这段）

| 角色 | 门店 | 地址 | 覆盖 | 到最近医院 |
|---|---|---|---|---|
| **主仓** | **Scarlett Westgate（裕廊东）** | #B2-01 Westgate, 3 Gateway Drive, 608532 | 全品类（拍板决定） | NTFGH 1.2 km |
| **分拨点 · 北** | **Scarlett Choice Northpoint City（义顺）** | #B2-101, 930 Yishun Ave 2, 769098 | KTPH 1.1 km / WH 7.0 km | 1.1 km |
| **分拨点 · 东北** | **Scarlett Hougang Mall** | #04-02, 90 Hougang Ave 10, 538766 | BGMP 2.4 / SKH 3.0 km | 2.4 km |
| **分拨点 · 南** | **Scarlett Bugis+** | #03-16/17, 201 Victoria Street, 188067 | SGH 4.7 / KKH 1.7 / TTSH 3.9 km | 1.7 km |

**效果**：14 家医院到"最近供货点"的路网距离之和 = **70.1 km**，
相比"只有主仓、不设分拨点"（231.6 km）省 **161.5 km（−70%）**，
相比现状方案（Kuehne+Nagel Pioneer 仓 + 同样三个分拨点，78.7 km）省 8.6 km。
最远单程 **10.9 km**（樟宜综合医院 CGH）。

**两个关键结论**：

1. **"北/东/南各一家"这个结构本身不花钱**：把候选按区域硬性约束后穷举 168 种组合，
   最优解 **就是**不限区域时的理论最优（约束代价 0.0 km）。
2. **唯一的取舍在"东部"的口径**：后港在官方规划区里属**东北区**（门店资料把它归东部）。
   - 按总距离最优（推荐）：后港 → Σ 70.1 km，但 CGH 要 10.9 km（全程最远）。
   - 若"东部"取**正东**（勿洛/淡滨尼/白沙）：Σ 升到 77.7 / 77.0 / 81.3 km，且最远反而升到 12.8 km（盛港），
     但 CGH 从 10.9 → **2.3 km**、PEH 从 7.1 → 4.7 km。
   - **建议**：主线用推荐方案（总距离与最远单程都更优）；若被问到"东部怎么没有点"，
     用备选方案并说明这是"东部专项覆盖"的取舍。

## 1. 方法与可复现性

| 环节 | 做法 |
|---|---|
| 门店清单 | Scarlett Supermarket 公开门店目录（[sggreatpromo](https://location.sggreatpromo.com/company/scarlett-supermarket)），共 20 家全岛门店进入候选池 |
| 门店坐标 | Nominatim（OpenStreetMap）地理编码，逐店核对；四家入选门店的坐标后由仓库正式生成流程重新编码，结果一致 |
| 路网 | `osmnx.graph_from_place('Singapore', network_type='drive')` → **23,828 节点 / 45,591 边** |
| 选路口径 | **与仓库脚本一致**：`add_edge_speeds(fallback=30)` → 按 `travel_time` 选最快路径 → 沿该路径累加 `length`，并行边取 `travel_time` 最小的一条（`scripts/build_singapore_network.py:29`） |
| 目标函数 | 主口径 `Σ_h min_{s∈S} dist(s, h)`（14 家医院各自取最近供货点，等价于每天固定订单的配送成本）；并列看 `max_h`（最远单程） |
| 穷举 | 主仓固定；北 4 × 东 7 × 南 6 = **168 种组合**全部算过 |

### 1.1 管线对账（为什么这些数字可信）

用同一套管线重算原有 15 个节点的 **105 对**距离/时长，与当时已提交的 `network.json.matrix` 逐对比较：

```
距离: 105 对 | 中位误差 0.0000% | 最大误差 0.0000%
时长:         | 中位误差 0.0000% | 最大误差 0.0033%
```

即与项目现用矩阵**零误差**，所以新增门店的数字与既有矩阵同源可比。

> 踩过的坑：第一版按"最短**距离**路径"算，比仓库矩阵系统性**偏短 5.9%**（最大 22%）。
> 原因就是仓库按 `travel_time` 选路——时间最优路径通常比距离最优更长。换成同一口径后误差归零。

### 1.2 重建时发现并修好的一个问题：H-SGH 一直在错的位置

把节点从 15 扩到 19、用仓库脚本重建矩阵后，原有 105 对里有 **14 对**发生变化（最大 +39%，全部与 SGH 相关）。
逐项核对后确认**不是回归，而是修好了一个错误的地理编码**：

| | 坐标 | 匹配到的对象 | 距 SGH 正门 |
|---|---|---|---|
| 旧（已提交的 15 节点矩阵） | 1.28944, 103.84474 | `type=administrative` —— **Singapore River 规划分区质心** | **1.55 km** ❌ |
| 新（本次重建） | 1.27945, 103.83627 | `type=hospital` —— SGH 本身（Chay Yan Street） | **0.14 km** ✅ |

其余 14 个旧节点坐标**零变化**（0.0 m）。所以旧矩阵里"到 SGH 的距离"一直是在量一个错的地方，
本次重建把它修正了。影响：KKH↔SGH 3.88 → 5.41 km、MEH↔SGH 3.36 → 4.26 km、PEH↔SGH 9.10 → 11.32 km 等。
**本页所有数字均已按修正后的矩阵重算**（这也是 Σ 从初版的 67.8 km 变为 70.1 km 的原因）。

**供货点分工**：Bugis+ 供 7 家、后港供 3 家、义顺供 2 家、主仓供 2 家。

SKH 只能由义顺供 **12.8 km**——这就是备选"最远单程反而升到 12.8 km"的来源。

### 3.3 主仓为什么可以是裕廊东（以及它的代价）

| 主仓候选 | 单仓覆盖 Σ（无分拨点） |
|---|---|
| **Westgate（裕廊东，指定并已落地）** | 231.6 km |
| Grantral Mall @ Clementi | **197.5 km** |
| Bukit Panjang Plaza | 225.5 km |
| 现状 K+N Pioneer 3PL 仓 | 323.1 km |

- Westgate 在**单仓口径**下不是最优（比 Clementi 差 34 km，因为它偏西）；但**加上分拨点后**，
  Westgate 方案 70.1 km、现状 K+N 配同样三个分拨点 78.7 km，差距只有 8.6 km。
- 且 Westgate 是 **Scarlett 全岛最大门店**（#B2-01，带 live seafood 与堂食），作为"全品类主仓"最站得住。
  **建议维持**，报告里写明"主仓偏西、由分拨点补覆盖"。
- 换成超市后，主仓与现状 3PL 仓（Pioneer）**同在新加坡西部**，地理格局没有剧变。

### 3.4 一个反直觉现象：单点排名会骗人

按"单独供货给 14 家医院"排序，北部最好是**宏茂桥（Σ 152.2 km）**，远好于义顺 Northpoint（226.1 km）——因为 AMK 更居中。
但在**组合**里必须选义顺：AMK 与武吉士覆盖重叠，选它就没人管北部两家医院（方案⑤里 KTPH 7.4 km、WH 10.4 km）。
**所以选点必须按组合优化，不能按单点排名挑。**

各区域单点前三（供参考）：北 AMK 152.2 / 义顺 226.1 / GV Yishun 228.5；东 Heartland 158.0 / Paya Lebar 164.6 / Hougang 171.6；
南 Bugis+ 139.4 / Suntec 149.3 / Chinatown Point 154.1；西 Clementi 197.5 / Bukit Panjang 225.5 / Westgate 231.6。

## 5. 假设与已知偏差（报告要写）

1. **门店是零售铺位，不是冷链仓**：四家门店均为商场铺位（`#B2-01` 等），无医药冷链资质。
   本方案把它们当作**前置仓/分拨点的模拟设定**，报告里必须声明；建议表述为"本项目假设连锁超市门店可作为区域分拨点"。
2. **坐标精度**：门店坐标来自 OSM 地理编码，多数精确到商场；勿洛那家匹配到 `New Upper Changi Road` **路段**
   而非具体门牌（该店未进最终推荐，影响有限）。
3. **清单时效性**：门店清单抓取于 2026-09-16。裕廊东店在 **Westgate**（门店目录 #B2-01）；
   JCube 商场已于 2023 年重建关闭，网上仍有旧文指向 JCube。
4. **自由流通行时间**：选路用 OSM 限速（`fallback=30`），不含拥堵、不含装卸停留。
5. **14 家医院等权**：目标函数把每家医院当同等需求；真实订单量不同，应加权后重算（改一行权重即可）。
6. **`can_terminate` 未参与选址**：本次只按"供货覆盖"选点；"哪些节点可作收车点"是另一个问题
   （方案 §4 停靠选址），两者可以不同。
