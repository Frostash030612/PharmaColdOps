## 4. 更新后的启停与回退

之后操作当前已启用实例，要同时带**两个env和两个Compose文件**：

```bash
docker compose --env-file deploy/demo.env \
  --env-file deploy/runtime/v2-shadow-20261004/shadow.env -p pharmacoldops-demo \
  -f deploy/compose.demo.yml -f deploy/compose.v2-shadow.yml ps

docker compose --env-file deploy/demo.env \
  --env-file deploy/runtime/v2-shadow-20261004/shadow.env -p pharmacoldops-demo \
  -f deploy/compose.demo.yml -f deploy/compose.v2-shadow.yml up -d --no-deps --no-build --wait api
```

只用基础Compose强制重建会去掉shadow开关／只读模型挂载，因此不能随手当成等价升级。
不要 `down -v`、删除任何现有卷或调用build_graph清空演示图谱。
紧急回退应用／关闭shadow（模型／audit／图谱仍保留，**本轮未实际执行回退**）：

```bash
DEMO_IMAGE=pharmacoldops-demo:pre-v2-shadow-20261004 \
docker compose --env-file deploy/demo.env -p pharmacoldops-demo \
  -f deploy/compose.demo.yml up -d --no-deps --no-build --force-recreate --wait api
```

回退旧前端不能展示新v2快照，不得将数据库恢复到旧备份而丢掉回退前已登记的新案例；若需恢复数据，
必须先停写、保留新备份、恢复到新目标并验证，不覆盖现有audit卷。
