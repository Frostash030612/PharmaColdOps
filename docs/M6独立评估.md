## 本轮真实运行

`scripts/evaluate_m6_independent.py prepare` 调用前端实际 `classifyQuestion`／`askKG`（Node worker），
不复制关键词表自造另一个分类器；识别后调用真实 `service.qa_view`，存档问题、案例事实、回答、证据与哈希。
未命中是客户端概念 FAQ 回退，不伪装成 `/api/qa` 结构化 unsupported 返回。

语料53条：原有37条FAQ关键词（原 expected_intent 全空，保持不动）＋16条明确标为开发者编写的中英文测试问句。
涵盖五种在线意图、超范围／效价证明问题、无案例。不是独立采样的真实用户语料，不能用于真实人群准确率推断。
本次实际12次服务查询、41次概念回退；41条回退不是人工判定的意图错误数，裸关键词可能有歧义。
最终包中12次服务函数调用中位数 **6.482ms**、p95 **16.820ms**，不含HTTP／浏览器／网络，也不是生产SLA或端到端时延。
准备时同机同时运行回归测试，时延不是隔离硬件基准。

同批57场景 **466/466派生检查通过**，验证案例记录一致、规则对应引用集合、阈值、状态及跨案例隔离；
这些期望值来自现有配置与引用映射，**不能独立证实引用相关性或领域结论正确**。
只新建专属 Neo4j 和 SQLite／JSONL，57评测案例／队列／归档清理完成，容器按创建ID移除；原项目图谱不启动、不重建。

## 两阶段人工流程与评分

1. 两位不同人工评审只收到盲意图材料和协议，独立填写全部53条；不看关键词实现、模型预测、回答或对方标签。
2. 标签封存后，才发实际回答和参考来源，填写 correctness／relevance／sufficiency 0–2，
   refusal 0–1或NA、unsupported_claims 0–1；记录真实查阅的来源URL。证据不适用可以NA，评分报告保留各项分母与NA数。
3. 一致意图作为参考；分歧由不同的第三人给最终单标签与理由。双方一致判断 ambiguous 可提供可接受意图集合，
   该行明确排除于单标签准确率分母，不能悄悄丢弃。当前仲裁要求一个最终标签；无法裁定时保持待评，不强造结论。
4. 提交四份完整CSV，必要时附仲裁CSV。评分拒绝空标签、缺行、重复行、不同包／响应指纹、同人双评、无来源记录或未仲裁。

```bash
.venv/bin/python scripts/evaluate_m6_independent.py score \
  --packet data/qa/m6-review-20261003-v3/coordinator/predictions.private.json \
  --intent-a data/qa/m6-review-20261003-v3/blind-intent/intent-A.csv \
  --intent-b data/qa/m6-review-20261003-v3/blind-intent/intent-B.csv \
  --ratings-a data/qa/m6-review-20261003-v3/answer-review/ratings-A.csv \
  --ratings-b data/qa/m6-review-20261003-v3/answer-review/ratings-B.csv \
  --output data/processed/m6-human-score-new
# 有分歧时另加 --adjudication 已填写的仲裁文件.csv
```

评分输出六类意图 accuracy／macro-F1／混淆／支持数、人工↔人工κ、歧义排除数，
各评审答案与证据评分、配对一致率，以及**双方均判正确性2的答案比例**，不强行把0–2平均分改名为准确率。
相关性是人工序数评分，不声称算出独立检索precision／recall。评审身份仅自报，脚本不能验证其真实身份或专业资质。
将来若增加自然采样问句、制造商资料或专家复核，应新版本评估，不覆写本包。
