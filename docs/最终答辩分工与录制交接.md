## PPT再生成与数字更新

构建脚本使用配置好的文档工具运行环境；正常使用者可直接在PowerPoint编辑已导出的最终副本。
保持原提案文件不动。M6正式报告到位后，将`--m6-report`指向协调人流程生成的report.json：

```text
node scripts/build_final_presentation.mjs --build-dir NEW_BUILD_DIRECTORY --output NEW_FINAL.pptx --runtime-modules BUNDLED_NODE_MODULES --runtime-python BUNDLED_PYTHON --skill-dir PRESENTATIONS_SKILL_DIRECTORY --verification RELEASE_REPORT.json --m6-report FROZEN_M6_REPORT.json
```

运行前查看`--help`；输出和构建目录须在工作区内且为新路径。需要`@oai/artifact-tool`文档运行环境，不要用运行API的依赖锁来假装已安装PPT构建依赖。
没有正式M6报告时省略该参数，PPT明确显示pending。无论有没有旧批成绩，当前修复版仍需要新的独立评价。
重导出后检查每页版式和备注，核对报告／视频数字；构建与格式检查不等于在原生PowerPoint逐项实测。
