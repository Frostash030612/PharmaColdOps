## 生成与拼接

依赖：Python 3.12、Pillow、numpy、`imageio-ffmpeg`（自带 libx264），以及 Windows 的 Segoe UI 字体。

```bash
python scripts/build_keynote_promo.py --out data/processed/keynote-promo-20261020
python scripts/build_keynote_promo.py --out data/processed/keynote-promo-20261020 --demo 路径/实机演示.mp4
python scripts/build_keynote_promo.py --out data/processed/keynote-promo-20261020 --draft 路径/5分钟画面草稿.mp4
python scripts/build_keynote_promo.py --out data/processed/keynote-promo-20261020/stills --stills 12,46 --parts a
```

`--demo` 会把演示缩放、加黑边到 1920×1080/30fps，按 A → 演示 → B 拼成 `PharmaColdOps-promotion.mp4`；
演示没有音轨时会自动补静音。输出在 git 忽略目录，视频文件不入库。
