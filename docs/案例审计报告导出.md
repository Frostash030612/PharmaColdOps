# 案例审计报告导出

案例详情的“人工审核与案例审计”提供两个下载入口：

- **HTML 报告**：单文件、无外部依赖，可离线打开，浏览器打印或另存 PDF。中英文标题和概览随页面语言切换。
- **JSON 完整快照**：保留所有原始数据、首次评估与审核／操作历史，便于复核和进一步处理。

当前不提供服务端直接生成的 PDF 文件；“另存 PDF”是浏览器打印能力。

## 包含什么

1. 案例身份、原登记时间／备注、订单、发生地点、产品、包装与阶段。
2. 原始规则建议、原阈值、rule_no、原引用映射、原启发式风险；不以人工结果覆盖。
3. M2 原温度区间、方法／参数／source hash、覆盖与窗口、选中范围；整段未评估／完全缺测不填假数值。
4. M4 保存的输入／模型标识／概率与候选／首次解释；不调用当前模型重算旧案例。
5. 当前有效处置、来源、审核状态、需补发、医院与执行锁。
6. 每次人工审核的姓名、时间、结论、理由、请求身份与版本；处理及结案说明。
7. 关联配送的当前持久化状态、版本、原订单、RO 补发和机械替代的后继订单；不混入无关订单。
8. 实际 Neo4j 原案例链的覆盖检查。图谱离线则明确 unavailable，不因 outbox 标 synced 就伪称图谱完整。

HTML 概览与可打印正文显示主要信息。温度长数组仅给计数、覆盖和前十个窗口等摘要，完整数据留在折叠的机器快照及 JSON 中，
避免默认打印上万区间。审核原文、备注、模型／规则字符串都经过 HTML 转义，不执行用户输入的脚本。
下载名只用安全 ASCII，响应 `Cache-Control: no-store`、`nosniff`，不把文件写入服务器公共目录。

## API

```text
GET /api/runs/{run_id}/audit?format=html&lang=zh
GET /api/runs/{run_id}/audit?format=html&lang=en
GET /api/runs/{run_id}/audit?format=json
```

未知案例 404，不支持的格式／语言 422。原始来源损坏／存储不可用时拒绝生成报告，不用不完整记录装成功。
仅图谱不可用不阻止原始 SQL／JSONL 报告，但会清楚列出未验证状态。
导出不登记、不改审核、不推进配送时钟、不重算规则、MKT 或 ML。审核／案例执行与快照读取共用动作保护。
配送部分是读取时的持久化状态与版本，不宣称真实 GPS、完整车辆日志或跨所有调度命令的数据库事务快照。

## 指纹与结论边界

JSON 带 `schema=pharmacoldops-case-audit-v1`、UTC 导出时间和 `content_sha256`。
SHA-256 对除 `exported_at`／`content_sha256`／`hash_scope` 外的整份 payload，按排序键、UTF-8、非 ASCII 原文序列化计算：

```python
payload = {k: v for k, v in report.items()
           if k not in {"exported_at", "content_sha256", "hash_scope"}}
digest = hashlib.sha256(json.dumps(payload, sort_keys=True,
                                 ensure_ascii=False, allow_nan=False).encode()).hexdigest()
```

它用于核对同一快照内容，**不是认证签名、不可篡改存证或法规合规证书**。
重新导出后若审核、配送或图谱状态发生变化，内容指纹应改变；原始登记与首次模型／温度结果仍保持不变。
旧时间戳原样保留，未带时区的旧记录不擅自补成 UTC。图谱证据解释原始判定，不代表已证实人工结论。
所有订单／传感数据和人员审核均处于演示边界，不授权现实世界的药品处置。
